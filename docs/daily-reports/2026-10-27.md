## 4. Risks & Blockers
- **Bug (confirmed in code):** `src/routers/tours.py:90` manually raises `HTTPException(status_code=422, detail=exc.errors())`. `exc.errors()` embeds the raw `ValueError` from the `@validator('artist')` in `src/schemas/tour.py:113-120` inside each error's `ctx`. FastAPI's generic exception handler serializes `exc.detail` with plain `json.dumps` (no `jsonable_encoder`), so the non-serializable `ValueError` crashes the response into a 500 instead of the intended 422.
  - **Fix options:** let Pydantic's `ValidationError` propagate and be handled by FastAPI's built-in `request_validation_exception_handler` (which uses `jsonable_encoder`), or manually build a JSON-safe detail payload (e.g. stringify errors) before raising `HTTPException`.
- No new PR mismatches detected this cycle — PRs #749–#751 diffs matched their claims on spot-check of schema/router files.
